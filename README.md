# ClimaShield

ClimaShield is a React Native app built with **Expo** for climate protection awareness. This repository contains the source code and assets for the mobile app.

---

## 📦 Prerequisites

Make sure you have the following installed:

- Node.js (>=16.x)
- npm or yarn
- Expo CLI: `npm install -g expo-cli`  
- Git
