# 🌍 ClimaShield

**ClimaShield** is a mobile application built using **React Native (Expo)** that focuses on **climate risk awareness and disaster-related health guidance**.  
The app aims to help users understand climate threats and take preventive actions using **AI-based predictions and insights**.

## 🚀 Features

- Climate risk awareness (heatwave, storm, flood, etc.)
- AI-based guidance and safety suggestions
- Clean and simple mobile UI
- Built with Expo for fast development
- Scalable for future AI/ML integration

---

## 🛠️ Tech Stack

- **React Native (Expo)**
- **JavaScript**
- **Node.js**
- **Expo CLI**

---

## 📦 Prerequisites

Make sure you have the following installed:

- **Node.js (>=16.x)**
- **npm or yarn**
- **Expo CLI**
  ```bash
  npm install -g expo-cli

🔧 Setup
1️⃣ Clone the repository
git clone https://github.com/Pratham9911/ClimaShield.git
cd ClimaShield

2️⃣ Install dependencies
npm install

3️⃣ Start the project
npx expo start


For web preview:

npx expo start --web
